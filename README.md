# OVER SSH PLUS MANAGER 🚀

Script profissional e moderno para gerenciamento de servidores SSH, WebSocket, V2Ray (VMess, VLESS, Reality), BadVPN UDPGW, Squid Proxy e controle de conexões.

---

### 📦 Instalação Rápida (Recomendado)

```bash
apt-get update -y && apt-get upgrade -y && wget https://raw.githubusercontent.com/koquebr/SSHPLUS/master/Plus && chmod +x Plus && ./Plus
```

---

### 🔑 Configurar / Liberar Acesso Root e Senha SSH

Caso precise liberar o login de ROOT e senha manualmente em qualquer VPS (Ubuntu 18/20/22/24, Debian 10/11/12, Oracle, AWS, etc.):

```bash
wget https://raw.githubusercontent.com/koquebr/SSHPLUS/master/senharoot.sh && chmod +x senharoot.sh && ./senharoot.sh
```

---
